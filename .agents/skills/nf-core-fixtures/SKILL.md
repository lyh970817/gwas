Use this skill when a module or subworkflow submission needs test data, when existing fixtures may be reused, or when a companion `nf-core/test-datasets` PR may be required. In design work, record the reuse-first search as an unresolved prerequisite rather than declaring a new fixture family warranted before that search.

## Standards cache fallback

If fallback is needed, relevant topic hints are:

- `docs/nf-core-standards/test-datasets.md`

- target-specific module or subworkflow standards files.

## Fixture decision process

1. Identify every input needed by the target tests and whether the output needs semantic correctness or only tool execution.
2. Search existing `nf-core/test-datasets` fixtures first, especially the `modules` branch.
3. Use `nf-core test-datasets list`, `list-branches`, or `search` where available to inspect existing data.
4. Prefer existing small fixtures even if the resulting biological output is minimal, as long as the tool executes and assertions are meaningful.
5. When an intermediate can be generated by an existing module in `setup {}`, prefer that over adding branch-local helper workflows or inline synthetic files, unless it makes the test less stable.
6. Add new test-datasets fixtures only when existing fixtures or practical setup-generated intermediates cannot cover the module adequately.

## Companion fixture submission

If new fixtures are required:

- Prepare them in the user's fork of `nf-core/test-datasets` at `~/Yandex.Disk/Projects/Research/nf-core/test-datasets`.
- Target the `modules` branch unless the user explicitly instructs otherwise.
- Use a dedicated test-datasets branch and in-repo worktree.
- Keep the fixture PR and module/subworkflow PR linked in their worktree-local `WORKTREE_PR.md` files.
- Keep fixture files as small as possible while still sufficient for stable tests.
- Do not push or open the fixture PR unless the user explicitly asks.

## Completion

Report the fixture choice, existing paths reused or new paths proposed, commands used to inspect datasets, and whether a companion fixture PR is required.
