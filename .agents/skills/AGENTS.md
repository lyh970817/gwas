# Agent skills

Each `SKILL.md` must contain a narrow frontmatter trigger and only the task procedure, sequencing, commands,
approval or stopping gates, evidence interpretation, and completion report needed when that trigger fires.

Stable repository, component, interface, public-boundary, and testing contracts belong in canonical tracked
documents indexed by `CODING_STANDARDS.md`. Cite the owner; do not copy its rulebook. Mechanically enforceable
formatting and configuration belong in the mechanism.

Validate changed skill frontmatter, local references, metadata, and trigger boundaries before committing.
