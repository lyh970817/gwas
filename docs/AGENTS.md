# Documentation

Apply [`CODING_STANDARDS.md`](../CODING_STANDARDS.md) to public documentation and assets. Files under
`docs/coding-standards/` are canonical stable-contract owners; update the owning document instead of duplicating
its rules in a skill or nested instruction.

`docs/nf-core-standards/` is an ignored generated cache governed by `nf-core-standards-refresh`; do not track or
edit it as part of ordinary guidance maintenance. `docs/agents/domain.md`, when present, is ignored local state
governed by `repository-domain-docs`.
